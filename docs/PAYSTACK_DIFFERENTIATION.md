# Paystack Differentiation

## Core Position

OpenBank NG is not sold as a replacement merchant account for Paystack.

Paystack sells payment processing as a service. OpenBank NG sells source-code
ownership of a Nigerian fintech infrastructure foundation.

That difference is the sales argument.

## Why A Buyer Would Choose OpenBank NG

### 1. Ownership Instead Of Only Usage

With Paystack, a buyer uses Paystack's hosted rails and merchant tools. With
OpenBank NG, the buyer receives source code, apps, API structure, database
schema, wallet/account workflow, ledger boundaries, provider adapters, admin
operations, and buyer documentation.

The buyer can inspect, modify, brand, extend, and operate their own platform
after completing the required legal, compliance, provider, and security work.

### 2. Multi-Provider Control

Paystack is one provider. OpenBank NG is structured as a platform layer that
can connect approved providers such as Paystack, Monnify, Flutterwave,
Interswitch, bank sponsors, identity providers, notification providers, and
sandbox rails.

The buyer can design for routing, fallback, reconciliation, and provider
independence instead of depending on one provider relationship.

### 3. Investor And Client Demonstration

Many founders, agencies, and operators need more than a payment link. They need
a credible fintech product foundation that can be shown to investors, clients,
technical reviewers, or regulated partners.

OpenBank NG gives them customer banking screens, an admin dashboard, API
documentation, transaction states, KYC workflow structure, and operating
controls they can demonstrate and customize.

### 4. Private-Label And Client Delivery

Agencies and fintech builders can use OpenBank NG as the base for one approved
client or internal product under the commercial license. That is a different
value proposition from signing up as a Paystack merchant.

### 5. Nigerian Operating Workflows

OpenBank NG includes Nigerian-oriented primitives and workflows:

- NGN/kobo money handling.
- Nigerian bank-code support.
- BVN/NIN-ready KYC fields.
- Wallet/account workflow.
- Transfer risk review.
- Admin approval flow.
- Notification outbox.
- Audit boundaries.
- Reconciliation support.
- Provider adapter design.

These are the pieces buyers need when they want to build a fintech operating
system, not only accept checkout payments.

## Buyer Qualification

OpenBank NG is a fit when the buyer says:

- We want to own and customize a fintech platform.
- We need a serious demo for investors or partners.
- We want a source-code base for a Nigerian wallet, neobank, cooperative,
  agency banking, or payment orchestration product.
- We need admin operations, ledger boundaries, audit logs, KYC flow, and
  provider integration structure.
- We understand that licensing, compliance, security review, and live provider
  approval are our responsibility.

OpenBank NG is not a fit when the buyer says:

- We only need a payment link.
- We do not want to manage source code.
- We expect a licensed payment processor out of the box.
- We want to go live without legal, compliance, provider, and security review.

## Sales Line

Do not buy OpenBank NG if you only need a simple payment link. Use Paystack.

Buy OpenBank NG if you want to own, customize, and launch a Nigerian fintech
infrastructure foundation with your own brand, providers, compliance process,
and operating model.
